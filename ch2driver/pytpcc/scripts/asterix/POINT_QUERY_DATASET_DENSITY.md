# Point-query PK sampling: dense vs non-dense datasets

Used by `create_point_queries_sqlpp.py` **`--mode random`**: datasets listed here as **non-dense** are **skipped automatically** (they still appear in **`--mode sweep`** with a stderr warning).

Data generation reference: `runtime/loader.py`, `constants.py`, `ddl/asterix/ch2pp_bench.sqlpp`.

## Automatically skipped in `--mode random`

| Dataset | Reason |
|---------|--------|
| **`nation`** | Only **62** valid `n_nationkey` values exist (see `constants.NATIONS`); they are **not** a contiguous run of integers. Uniform sampling in a min–max **range** mostly misses. |
| **`history`** | Asterix DDL: **`_id uuid`**, **`AUTOGENERATED`**. No client-chosen integer PK; cannot generate random PKs without reading existing rows. |

## Dense in the usual CH2++ load (safe for box sampling with matching bounds)

If `--warehouses`, `scaleFactor`, and column bounds match the load, independent uniforms over these boxes align with **Loader** output:

| Dataset | PK | Notes |
|---------|-----|--------|
| `warehouse` | `w_id` | One row per loaded `w_id`. |
| `district` | `d_w_id`, `d_id` | Grid: each loaded `w` × `d_id` 1..10 (default). |
| `customer` | `c_w_id`, `c_d_id`, `c_id` | Grid per district; `c_id` 1..`customersPerDistrict`. |
| `stock` | `s_w_id`, `s_i_id` | Grid: each `w` × each item 1..`items`. |
| `orders` | `o_w_id`, `o_d_id`, `o_id` | One order per `(w,d,o_id)` for `o_id` 1..`customersPerDistrict`. |
| `neworder` | `no_w_id`, `no_d_id`, `no_o_id` | **Only** for `no_o_id` in the **last** `newOrdersPerDistrict` ids (default **2101..3000** when `customersPerDistrict=3000` and `newOrdersPerDistrict=900`). Random mode uses these defaults for `no_o_id`. Sampling **1..3000** uniformly would **not** be dense in neworder. |
| `item` | `i_id` | `1..scaleParameters.items`. |
| `supplier` | `su_suppkey` | `1..10000`. |
| `region` | `r_regionkey` | `0..4` (5 regions). |

## Cartesian size vs global `--count`

`--mode random` draws **`count` distinct** random PK tuples per **remaining** dataset. If  
**Π (max − min + 1)** over PK columns **&lt; `count`**, that dataset is **skipped** with a note.
